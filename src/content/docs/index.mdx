## What this site is

A **companion guide** to [Cole Medin's Agentic Coding Course V2](https://discover.circle.so/products/dynamous-ai-mastery). Not a replacement for the videos — a reference you come back to.

The course teaches you to build an **AI Layer** (your harness) around your coding agent. This site gives you deep dives on the pieces that layer is made of.

**Two ways to use this site:**
- **Lookup mode:** Use alongside the videos. When Cole introduces a primitive, come here for the details. Jump around by topic using the sidebar.
- **Learning path:** If you're exploring without the course, start with [The Five Primitives](/primitives/overview/) and follow the links forward.

## The core ideas

Three ideas run through everything here:

1. **Your agent is only as good as the system around it.** The model is the easy part. The hard part is building the context, the constraints, and the workflows that make the model useful *your* way.

2. **It's all just markdown.** Rules, skills, agent files — they're all markdown with some YAML. What's different is how they load and what tools they can access. Composing your system is writing, not wiring.

3. **Build the thing that builds the thing.** Don't just use the primitives. Teach your agent to build them *your* way, so every new skill, every new hook comes out shaped the way you'd shape it.
