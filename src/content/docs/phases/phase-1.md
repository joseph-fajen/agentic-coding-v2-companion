Phase 1 is the **"Use"** stage — you install the mental models, stand up an AI Layer on a project you actually care about, and ship one real ticket end to end through the full loop.

**Weeks 1–3 · Videos V1–V11**

## What you'll walk away with

- **The whole loop held in your head:** strategic doc → Layer 1 / Layer 2 planning (stable context vs per-feature planning) → the R-PIV loop (Research → Plan → Implement → Validate) → system evolution.
- **A working AI Layer** customized to your stack. Global rules first; the rest of the primitives come in Phase 2.
- **One real ticket shipped** through the full R-PIV loop on your own [greenfield or brownfield](/glossary/#greenfield--brownfield) project (a new one, or one that already exists).

## The Phase 1 thesis

Using AI to code is table stakes. The edge is running a *system*: you own the planning, architecture, and validation — the agent owns the implementation. Phase 1 installs that mental model and gets the system running on *your* work.

## How Phase 1 teaches

- **One mental model per video**, shown on a real codebase (the AI Tutor), then applied to *your* project.
- **Brownfield-first**, with the greenfield path called out at every step.
- **Short and concept-first.** Most videos run ~10 minutes; the foundational ones run longer where the idea earns it.

## Key concepts

### Layer 1 / Layer 2

**Layer 1** is the stable, always-on context that lives in your rules and steering docs. **Layer 2** is the per-feature plan — the specific research and implementation approach for one ticket. Phase 1 teaches both and shows how they interlock.

### The R-PIV loop

Research → Plan → Implement → Validate. You own research and plan (the judgment). The agent owns Implement. You return for Validate. This division is what makes the system trustworthy — and sharpening it is what Phase 3 is about.

### System evolution

Every gap you notice during validation updates a rule, a plan template, or a habit — so the next loop is better. This is introduced in Phase 1 and becomes Phase 3's spine.
