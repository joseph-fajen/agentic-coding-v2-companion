---
title: The Five Primitives
description: Overview of the five building blocks of agentic coding
---

The five primitives are the core building blocks of Claude Code agentic systems:

1. **Rules** — CLAUDE.md and steering documents that guide agent behavior
2. **Subagents** — Specialized agents spawned for specific tasks
3. **MCP / Tools** — Model Context Protocol servers and tool integrations
4. **Skills** — On-demand capability packages loaded via triggers
5. **Hooks** — Pre/post execution hooks for validation and automation

Each primitive serves a distinct purpose in the agentic coding workflow.
